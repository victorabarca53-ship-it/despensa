# Despensa

App para el celular (PWA): despensa, lista de compras, platos rápidos y registro de hábitos
(proteína, agua, sueño, peso y actividad). Funciona sin señal.

Este repositorio tiene **solo la app**. No trae datos de nadie: cada persona carga los suyos
desde un archivo y quedan guardados únicamente en su teléfono (IndexedDB).

- Chart.js 4.4.1 (MIT) y fuentes Sora e Inter (OFL) en `vendor/`.
